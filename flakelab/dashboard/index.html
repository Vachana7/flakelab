How to read this

Each condition changes one thing about the environment. FlakeLab runs the full test suite many times under each condition, in interleaved order, then compares failure rates with the baseline using Fisher's exact test and the Holm-Bonferroni correction.

A confirmed observation is a measured difference. A supported hypothesis is what that difference suggests about the cause. It is an association, not proof. Unknown means the test is unreliable but no tested condition explains it.
